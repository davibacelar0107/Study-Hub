# Study-Hub

Logica-de-Programacao
Nesta disciplina, serão abordados conceitos e definições da lógica e sua aplicação.

Vimos:

-A logica realizada para a programação
-Linguagem natural, fluxograma e pseudocodigo
-Portugol webstudio
-Linguagem C

Introdução a computação
Nesta matéria aprendemos sobre as programações mais próximas da máquina, além de ver sobre algumas peças do hardware

Vimos: 
-Transparências de números binários -Transparências de Princípios de Organização de computadores -Transparências de Software e Sistema Operacional -Introdução a pilha da rede

Bootcamp-I
Essa é a matéria do meu curso que me apoia e ensina a realizar o projeto do Study Hub. Nela nós utilizamos diversas ferramentas que auxiliam os estudos e que futuramente poderemos atualizar para conseguir alguns trabalhos desejados.

Fundamentos-da-Engenharia
Nessa matéria, nos aprendemos sobre os fundamentos das engenharias, além da de software

Vimos sobre:

-Ciência dos Materiais, Química Básica e Ciência dos Ambiente
-Transferência de Calor e Massa
-Mecânica dos Sólidos
-Expressão Gráfica - CAD

Banco-de-Dados-I
Nesta materia nos compreendemos os conceitos fundamentais e a arquitetura de um sistema de banco de dados; Projetamos e modelamos bancos de dados relacionais a partir de requisitos; Escrevemos queries em SQL para definir, manipular e extrair dados de bancos relacionais

Vimos:

-Introdução aos Sistemas de Banco de Dados
-Projeto de Banco de Dados
-Metodologia Entidade-Relacionamento (ER)
-Normalização de Dados
-SQL Básico
-Modelagem Multidimensional

Engenharia-de-Software
Nesta materia temos como objetivo, ser capacitado no conhecimento dos conceitos de engenharia de software, com enfase em qualidade de software e nas melhores praticas de desenvolvimento

Devemos:

-Desenvolver uma visão sistêmica dos conceitos de Engenharia de Software
-Compreender de forma ampla as etapas do processo de desenvolvimento de software
-Compreender o papel do Engenheiro de Software
-Desenvolver expressão e comunicação, estabelecer relacionamentos e redes colaborativas, compatíveis com o exercício profissional.
