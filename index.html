Sobre o projeto

O Study Hub nasceu como um espaço para organizar o que é aprendido em cada matéria. O repositório descreve cada disciplina e lista os conteúdos vistos, funcionando como um índice de estudo.

Segundo o README, a disciplina Bootcamp-I apoia e orienta a realização do projeto. Nela são usadas ferramentas que auxiliam os estudos e que poderão ser atualizadas no futuro.

Estado atual: o repositório contém um único arquivo, o README.md, e ainda não possui código de aplicação. Esta página apresenta o que está documentado nele e será mantida fiel ao conteúdo real do projeto.

Disciplinas registradas

O conteúdo atual do repositório. Abra cada item para ver os temas listados no README.

Lógica de Programação

Conceitos e definições da lógica e sua aplicação.

  • A lógica aplicada à programação
  • Linguagem natural, fluxograma e pseudocódigo
  • Portugol Webstudio
  • Linguagem C
Introdução à Computação

Programação mais próxima da máquina e noções de hardware.

  • Números binários
  • Princípios de organização de computadores
  • Software e sistema operacional
  • Introdução à pilha da rede
Bootcamp-I

Disciplina que apoia e ensina a realização do projeto Study Hub, com o uso de ferramentas que auxiliam os estudos.

Fundamentos da Engenharia

Fundamentos das engenharias, incluindo a de software.

  • Ciência dos Materiais, Química Básica e Ciência do Ambiente
  • Transferência de Calor e Massa
  • Mecânica dos Sólidos
  • Expressão Gráfica (CAD)
Banco de Dados I

Conceitos e arquitetura de bancos de dados, modelagem relacional a partir de requisitos e consultas em SQL para definir, manipular e extrair dados.

  • Introdução aos Sistemas de Banco de Dados
  • Projeto de Banco de Dados
  • Metodologia Entidade-Relacionamento (ER)
  • Normalização de dados
  • SQL básico
  • Modelagem multidimensional
Engenharia de Software

Conceitos de engenharia de software, com ênfase em qualidade e boas práticas de desenvolvimento.

  • Desenvolver visão sistêmica dos conceitos da área
  • Compreender as etapas do processo de desenvolvimento
  • Compreender o papel do engenheiro de software
  • Desenvolver comunicação e redes colaborativas compatíveis com o exercício profissional
